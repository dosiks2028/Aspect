# Row Five

A responsive student project for choosing movies and series by mood, searching a catalog, and keeping a watchlist in the browser.

## Pages

- Home: weekly picks, local demo voting, and demo account registration.
- Movie Picker: mood-based recommendations and a demo reservation form.
- Catalog: searchable movie collection and watchlist controls.
- Series: searchable TV guide and a demo suggestion form.
- About: project credits, FAQ, and demo feedback form.
- Profile: local demo login and saved items.

## Run locally

Open `index.html` in a browser or serve this folder with a local static web server. The site uses Bootstrap 5.3.3 and jQuery 3.7.1 from their CDNs.

Accounts, votes, watchlist items, and demo reservations use this browser's `localStorage`. Forms do not send messages, email, or payments. Do not use a real password.

## Assignment

Created for Web Technologies 1. The site includes responsive layouts, light and dark themes, form validation, saved state, and jQuery effects.
